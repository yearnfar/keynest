# Wails v3 Build Assets

This directory contains the Wails v3 Taskfiles, package metadata, and platform assets used by `wails3 build` and `wails3 package`.

- Edit application metadata and file associations in `config.yml`.
- Run `wails3 task common:update:build-assets` after changing that metadata.
- Replace `appicon.png` to update generated macOS and Windows icons.
- Build output is written to the repository-level `bin/` directory.

Platform Taskfiles are generated by Wails v3. Keep project-specific build commands in the root `Taskfile.yml` and `Makefile`.
